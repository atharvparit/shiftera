# ShiftEra

### Workforce Intelligence for a Changing Labour Market

ShiftEra is a location-aware workforce intelligence platform
designed to identify emerging skill demand, supply-demand gaps,
curriculum mismatches, and personalized skill requirements.

Built for Smart India Hackathon 2026 — Problem Statement 26134.

## Problem

The skills taught by educational and training institutions
often do not keep pace with changing industry requirements.

ShiftEra connects:

Labour Market Demand
        ↓
Skill Intelligence
        ↓
Supply-Demand Gap
        ↓
Curriculum Alignment
        ↓
Student Skill Gap
        ↓
Actionable Recommendations

## Key Features

- District-level labour market intelligence
- Skill demand and growth analysis
- Supply-demand gap analysis
- Student skill-gap recommendations
- Curriculum intelligence
- Explainable recommendations
- ML-ready workforce intelligence architecture

## Current Prototype

The current MVP uses representative prototype data and a
deterministic recommendation engine.

It does not currently claim to use live job-market data or
production ML forecasting.
